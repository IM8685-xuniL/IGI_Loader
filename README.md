# Project I.G.I Loader
This is a Loader for the game which makes it playable if you have any kind of visual artifacts.<br>
[![As shown in this video.](https://img.youtube.com/vi/YOUTUBE_VIDEO_ID/0.jpg)](https://www.youtube.com/watch?v=84Qbswo6qUg)



###### check if the loader is able to be used on windows as I am using it on Linux. 


For this to work just download the files and get the following files into your clipboard(ctrl+V):-<br>

-Project I.G.I.md<br>
 -Project I.G.I.mds<br>
   -IGILoader.exe<br>
    -InjectIGI.dll


Into the games directory i.e   [Dir..]/pc the folder containg the .exe of the game, now run the game by using the Loader (run the IGILoader.exe).Some issues I have seen is mostly every trainer(s) or mod(s) that are currently available cannot be used when running the game through this loader as those trainer(s) check for IGI.exe running on your system even the patch's' (that is provided by Blankspace) debugkeys also does not work.
